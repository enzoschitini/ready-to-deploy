# Ready To Deploy

![Ready To Deploy](assets/imgs/reademe_cover.png)

**Python from zero to your first deploy.** A free, open-source course for absolute beginners who
want to stop watching tutorials and put real code into production.

🌐 **[enzoschitini.github.io/ready-to-deploy](https://enzoschitini.github.io/ready-to-deploy)**
🇧🇷 Português · 🇮🇹 Italiano

## What you'll learn

The course covers the "Python na Prática" bootcamp end to end, from installing Python to writing
your first classes — nine modules, each with a hands-on practical project:

1. **Scripting** — installing Python, running code from the terminal, creating script files
2. **Variables and data types** — variables, numbers, strings, booleans
3. **Conditional flow and loops** — conditionals, `for`, exceptions
4. **Data structures** — lists, dictionaries, sets
5. **Files and functions** — reading/writing files, functions, scope
6. **Error handling** — syntax, runtime, and logic errors
7. **Modules and packages** — `import`, modules, packages, `pip`
8. **Functional programming** — `lambda`, `map`, `filter`, `reduce`
9. **Object-oriented programming** — classes, objects, inheritance

Every module ends with a guided practical project, so you're always applying what you just
learned instead of just reading about it.

## How the course works

The site is a static HTML/CSS/vanilla-JS course platform — no build step, no framework, no
account required. Pick a language, pick a module, and start reading. Lessons and projects live
directly on the site; nothing to install beyond a browser (and later, Python itself).

## Contributing

Ready To Deploy is open source and welcomes contributions — new modules, practical projects, or
improvements to existing content. Contributors work with raw material and Jupyter notebooks; you
don't need to touch the site's code or run any build tooling.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide (also available in
[português](contributing/contribuição.md) and [italiano](contributing/contributo.md)).
