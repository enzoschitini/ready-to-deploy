# Generated modules (output)

The `.ipynb` modules generated by the `gerar-modulo-ipynb` *skill* from the material in
[`../../raw_content/`](../../raw_content/) live here, named `module_NN.ipynb` (two digits:
`module_07`, not `module_7`).

Before opening the *pull request*, open the notebook in Jupyter or Colab and run **"Run all"**.
To validate structure and execution:

```bash
python .claude/skills/gerar-modulo-ipynb/scripts/validar_notebook.py \
  contributing/generated_ipynb/modules/module_NN.ipynb
```

Once approved in the *pull request*, the author moves the notebook to
`bootcamps/<lang>/<bootcamp>/Módulos/` and publishes the site pages. Full walkthrough in
[`CONTRIBUTING.md`](../../../CONTRIBUTING.md).
