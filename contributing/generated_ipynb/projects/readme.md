# Generated practical projects (output)

The practical-project `.ipynb` files generated by the `gerar-projeto-pratico-ipynb` *skill*
live here, named `project_NN.ipynb`, where `NN` is the number of the corresponding module (two
digits).

The project's source can be a module from [`../modules/`](../modules/), a module already
published in `bootcamps/<lang>/<bootcamp>/Módulos/`, raw content from
[`../../raw_content/`](../../raw_content/), or a combination of these.

Before opening the *pull request*, run the notebook the way a student would receive it (cells
as delivered, before writing any solution). To validate:

```bash
python .claude/skills/gerar-projeto-pratico-ipynb/scripts/validar_projeto.py \
  contributing/generated_ipynb/projects/project_NN.ipynb
```

Once approved, the author moves the notebook to `bootcamps/<lang>/<bootcamp>/Projetos/`. Full
walkthrough in [`CONTRIBUTING.md`](../../../CONTRIBUTING.md).
